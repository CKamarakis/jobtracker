```
JOB SOURCES                  DETERMINISTIC INGEST (no LLM)         LLM LAYER (human-gated)
┌─────────────┐    ┌──────────────────────────────────────┐   ┌────────────────────────┐

                   │  → 10 exact / 8 adj / 0 far   │            (DRAFTS — human applies)
                   └───────────────────────────────┘
```

**Key components, one line each:**
- **ingest/run.py** — daily loop: fetch each source, dedup/merge into pool, gate new records; LLM-free so it can't hallucinate.
- **store.py** — `job_key` (location-free, gender-stripped hash) + `merge_job` rules; the silently-destructive core, pinned by 29 unit tests.
- **filters.py** — `prefilter` gate stamps off-target new records `skipped`+reason (still stored, not deleted).
- **adzuna.py / arbeitnow.py** — source adapters, identical `fetch()→list[dict]` contract; Adzuna is phrase-targeted discovery, Arbeitnow ingests the whole board.
- **triage / cover-letter / research** — three isolated-context subagents; the only LLM judgment, all human-reviewed.
- **cover-voice / dossier** — skills encoding fixed voice + sourcing discipline (every claim cites a URL or `unknown`).
- **run_eval.py** — feeds 18 labeled jobs blind at temp=0; reports agreement; disagreements = unwritten criteria.

## 2. Key achievements
- **Trustworthy eval harness** — temp=0 made the grader repeatable; baseline **10 exact / 8 adjacent / 0 far misses** on 18 gold jobs.
- **Two live sources shipped** — Arbeitnow + Adzuna, both deterministic, unified contract; pool at **1028**.
- **Dedup/merge hardened + tested** — location-free key, cross-source/cross-run merge, 29 green unit tests.
- **Rubric's one systematic error caught & fixed** — company-size hard-cliff → graduated soft drag (factor 10); killed the only far miss.
- **Prefilter wired** into the new-record branch (83 already gated).
- **Rich primitive coverage for the learning goal** — agents, skills, evals, unit tests all in play with banked rationale.

## 3. Key troubles & learnings
- **Stochastic grader at small n = noise-chasing** → fixed with temp=0; banked lesson: determinism or k-sample before tuning.
- **Arbeitnow pool bloat (OPEN)** — ~893 records = whole-board hoard (no keyword filter), not useful PM ads. Diagnostic was interrupted.
- **Adzuna gotchas** — descriptions truncated to ~500 chars (discovery only), remote flag unreliable, fuzzy German stemming leaks off-target roles.
- **Overfitting frontier** — at 0 far misses, further micro-tuning on 18 cases is noise; grow the gold set reactively instead.
- **No live triage run yet** — all 945 records still `status:"new"`; the system has never been run end-to-end on real data.

## 6. Definition of done (PROPOSAL)
- **Per-run DoD:** `python ingest/run.py` → realistic pool → triage outputs an ordered fit matrix → ≥1 shortlist with drafted cover + dossier → **human reviews, human applies.** System never submits.
- **System DoD:** Chris runs this daily with trust; triage agreement holds on a growing gold set; new sources slot in via the `fetch()` contract without touching the core.

## 7. Success / failure measures (PROPOSAL)
- **Eval agreement** — exact+adjacent rate on gold set; **far misses → 0 is the real bar.** (Primary, already instrumented.)
- **Pool precision** — % of `new` (un-skipped) records that are genuinely PM-relevant. Today: unknown, suspected low → the Arbeitnow problem.
- **Funnel yield** — pool → shortlisted → applied → interview. The only externally-meaningful metric; not yet tracked (needs status lifecycle in use).
- **Failure signals** — a hard reject landing in shortlist; any hallucinated fact in a dossier; voice drift in a letter.
- **Reasoning:** eval = quality of judgment; precision = quality of intake; funnel = real-world outcome. First is built; other two need a live run to populate.
